# 创建 fat-tv GitHub 仓库 - 详细步骤（图文版）

## 第一步：打开 GitHub 网站

1. 浏览器访问：https://github.com
2. 如果已登录，直接看下一步；如果没登录，点右上角 **Sign in** 登录，或点 **Sign up** 注册新账号

---

## 第二步：进入创建仓库页面

**方法 A（推荐）：**
1. 页面右上角，你的头像旁边有一个 **`+`** 号按钮
2. 点击 **`+`** → 下拉菜单中选 **New repository**

**方法 B：**
1. 直接访问：https://github.com/new

---

## 第三步：填写仓库信息

你会看到一个表单，按下图填写：

| 字段 | 填写内容 | 说明 |
|------|---------|------|
| **Repository name** | `fat-tv` | 仓库名称，必须填，建议用小写字母和连字符 |
| **Description** | `红米R70A电视音乐播放器` | 仓库描述，可选，填了更容易被搜索到 |
| **Public / Private** | 选 **Public** | 公开仓库免费，Private 需要付费（或有限免费额度） |
| **Add a README file** | ✅ **勾选** | 添加一个 README 文件，让仓库有初始内容 |
| **Add .gitignore** | ❌ 不勾选 | 不需要，我们项目里已经有 .gitignore 了 |
| **Choose a license** | ❌ 不勾选 | 可选，暂时不需要 |

2. 等待 2-3 秒，页面跳转到新创建的仓库主页
3. 你现在能看到 `https://github.com/你的用户名/fat-tv`

## 第六步：推送代码到仓库（自动触发编译）

在你的 `fat-tv` 项目文件夹内操作：

### 1. 打开 Git Bash

进入项目文件夹，在空白处 **右键 → Git Bash Here**

### 2. 依次执行以下命令

```bash
# 1. 初始化 Git 仓库
$ git init

# 2. 添加所有文件到暂存区
$ git add .

# 3. 提交（创建第一个版本）
$ git commit -m "Initial commit: fat TV music player"

# 4. 创建 main 分支
$ git branch -M main

# 5. 连接远程仓库（将"你的用户名"替换为实际用户名）
$ git remote add origin https://github.com/你的用户名/fat-tv.git

# 6. 推送代码到 GitHub
$ git push -u origin main
```

### 3. 输入账号验证

如果提示输入用户名和密码：
- **Username**: 你的 GitHub 用户名
- **Password**: 不是你的登录密码！需要用 **Personal Access Token**（见下方说明）

---

## 如何获取 Personal Access Token（因为 GitHub 不再支持密码推送）

2021 年后 GitHub 出于安全考虑，不再允许直接用账号密码推送代码，需要用 Token 代替。

### 创建 Token 步骤：

1. 访问：https://github.com/settings/tokens
2. 点击右上角 **Generate new token (classic)**
3. 填写：
   - **Note**: `fat-tv-push`
   - **Expiration**: 选 `No expiration`（永不过期）或 30 天
   - **Select scopes**: 勾选 `repo`（完整控制仓库）
4. 点击底部 **Generate token**
5. **立即复制显示的 Token**（页面关闭后无法再次查看！）
6. 这就是你 push 代码时用的 "密码"

## 第七步：等待自动编译并下载 APK

代码推送成功后：

1. 打开你的仓库页面：`https://github.com/你的用户名/fat-tv`
2. 点击顶部的 **Actions** 标签
3. 你会看到一个正在运行的 workflow（黄色圆圈 🟡）
4. 等待 5-8 分钟
5. 变成绿色对勾 ✅ 表示编译成功
6. 点击进入这个 workflow run
7. 滚动到页面最底部，找到 **Artifacts** 区域
8. 点击 **fat-tv-debug-apk** 下载 APK 文件

## 遇到问题？

- **git push 失败提示 403**：用 Personal Access Token 替代密码
- **Actions 显示红色 ❌**：点击 workflow 查看具体错误，通常是网络波动导致依赖下载失败，点击 "Re-run jobs" 重新运行即可
- **找不到 Download 按钮**：确保 workflow 已完全运行结束（显示 ✅），Artifacts 在页面最底部
